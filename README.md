# 3D Student Portfolio Interactive Experience

Welcome to this interactive 3D platform designed to showcase the amazing technical projects created by my elementary and middle school computer science students. 

This virtual exhibition hall was built collaboratively in the classroom by myself and the students. It serves as a dynamic gallery to highlight our absolute favorite projects out of the hundreds we have developed together during our classes. Step inside, walk around, and explore the creativity of the next generation of developers and designers!

### Features
* **First-Person 3D Navigation:** Explore the gallery using standard WASD and mouse controls.
* **Three Interactive Rooms:** Dedicated spaces for Arcade Games, Web Development, and UX Design.
* **Figma-Style UX Canvas:** The UX room features a custom-built infinite canvas with drag-to-scroll and dynamic zoom to explore full-scale app and web mockups.
* **Bilingual UI:** Real-time toggling between English and Spanish.
* **Responsive 2D Quick View:** A fast, grid-based alternative viewing mode.

### Technologies Used
* **Core:** HTML5, CSS3, JavaScript (ES6+)
* **3D Engine:** Three.js (WebGL) & PointerLockControls
* **Styling & UI:** Tailwind CSS (Glassmorphism & Neon UI design)
* **Interaction:** Panzoom (for the UX infinite canvas mode)

# Portafolio Estudiantil 3D - Experiencia Interactiva

Bienvenidos a esta plataforma interactiva en 3D diseñada para exhibir los increíbles proyectos técnicos creados por mis alumnos de primaria y secundaria en la clase de informática.

Esta sala de exhibición virtual fue construida de manera colaborativa en el aula por mí y los estudiantes. Sirve como una galería dinámica para destacar nuestros proyectos favoritos absolutos de entre los cientos que hemos desarrollado juntos durante nuestras clases. ¡Entra, camina y explora la creatividad de la próxima generación de desarrolladores y diseñadores!

### Características
* **Navegación 3D en Primera Persona:** Explora la galería usando los controles estándar WASD y el ratón.
* **Tres Salas Interactivas:** Espacios dedicados para Juegos Arcade, Desarrollo Web y Diseño UX.
* **Lienzo UX estilo Figma:** La sala UX cuenta con un lienzo infinito personalizado con desplazamiento de arrastre y zoom dinámico para explorar maquetas de aplicaciones y webs a escala real.
* **Interfaz Bilingüe:** Cambio en tiempo real entre Inglés y Español.
* **Vista Rápida 2D Responsiva:** Un modo de visualización alternativo rápido basado en cuadrícula.

### Tecnologías Utilizadas
* **Núcleo:** HTML5, CSS3, JavaScript (ES6+)
* **Motor 3D:** Three.js (WebGL) y PointerLockControls
* **Estilos e Interfaz:** Tailwind CSS (Diseño Glassmorphism y UI Neón)
* **Interacción:** Panzoom (para el modo de lienzo infinito UX)
